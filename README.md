# 🥋 KATA SCORER

A simple, responsive scoring display for individual judges in Karate Kata competitions.

## 🌐 Live Website

**[Open KATA SCORER](https://kraghavan07.github.io/kata-scorer/)**

## ✨ Features

- AKA (Red) and AO (Blue) competitor selection
- Score selection from 5.0 to 10.0 in 0.1 increments
- Large, high-contrast score display
- Disqualification option
- Confirmation before starting a new round
- Fullscreen support
- Responsive layout for phones, tablets, and computers
- Orientation prompts for portrait and landscape use

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- GitHub Pages

## 📱 How to Use

1. Open the live website.
2. Select AKA or AO.
3. Adjust the score using the available controls.
4. Select **SHOW SCORE** to display the score.
5. Use **CHANGE SCORE** to return to the selector.
6. Follow the on-screen confirmations when disqualifying a competitor or starting a new round.

## ⚠️ Disclaimer

This is an individual judge's scoring display tool. Scores are recorded and results are determined separately by the competition officials.

This project is not officially endorsed by the World Karate Federation (WKF).
